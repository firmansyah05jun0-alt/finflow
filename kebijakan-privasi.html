Kebijakan Privasi FinFlow

PrivasiKetentuan PremiumKontak

Ringkasnya: catatan keuanganmu disimpan di HP kamu sendiri. Kami tidak memasang iklan, tidak melacak aktivitasmu, dan tidak menjual data. Data baru keluar dari HP jika kamu sendiri menyalakan sinkron Google Sheets atau mengaktifkan kode Premium.

1. Data yang disimpan di perangkatmu

  • Nama panggilan, username, dan hash PIN (PIN aslinya tidak disimpan).
  • Transaksi, dompet, kategori, budget, target tabungan, utang-piutang, dan transaksi rutin yang kamu catat, termasuk nama dan nomor WhatsApp orang yang kamu isi di catatan utang.
  • Foto struk yang kamu lampirkan (dikompres, hanya di HP ini).

Data ini tersimpan di penyimpanan browser/aplikasi pada perangkatmu dan tidak kami terima. Jika kamu menghapus data browser, mencopot aplikasi, atau kehilangan HP tanpa backup, data tersebut hilang. Gunakan fitur Backup secara rutin.

2. Sinkron Google Sheets (opsional)

Jika kamu menyalakan sinkron, data catatan keuangan dikirim ke Google Sheet melalui Google Apps Script pada alamat yang kamu atau admin pasang. Siapa pun yang memiliki Sheet tersebut dapat membaca isinya. PIN tidak dikirim; yang dikirim adalah token turunan PIN, dan server hanya menyimpan hash-nya. Foto struk tidak ikut disinkron.

3. Lisensi Premium

Saat kamu mengaktifkan kode Premium, aplikasi mengirim ke server lisensi milik pengelola: kode Premium, ID perangkat acak yang dibuat aplikasi (bukan IMEI, nomor HP, atau data akun Google), versi aplikasi, dan waktu aktivasi. Aplikasi mengecek ulang status kode secara berkala saat online. Data catatan keuanganmu tidak dikirim ke server lisensi. Pengelola juga dapat mencatat nama/kontak pembeli yang kamu berikan saat membeli, untuk keperluan layanan pelanggan.

4. Layanan pihak ketiga

  • Google Fonts untuk huruf, dan cdnjs (Cloudflare) untuk pustaka pembuat PDF/Excel saat fitur itu dipakai. Seperti saat membuka situs web biasa, penyedia ini dapat melihat alamat IP dan jenis browsermu.
  • Google Apps Script / Google Sheets bila sinkron atau lisensi dipakai.
  • WhatsApp hanya terbuka bila kamu menekan tombol "Ingatkan via WhatsApp".
  • Tempat hosting situs aplikasi (mis. [Netlify / GitHub Pages]) dapat mencatat log akses standar.

5. Yang tidak kami lakukan

  • Tidak ada iklan, pelacak, atau analitik pihak ketiga.
  • Tidak menjual, menyewakan, atau membagikan data pribadimu.
  • Tidak meminta akses kontak, lokasi, atau galeri di luar foto yang kamu pilih sendiri.

6. Keamanan

PIN disimpan dalam bentuk hash dan bisa dipakai untuk mengunci aplikasi. PIN adalah kunci aplikasi, bukan enkripsi penuh, jadi jaga HP-mu dan gunakan PIN yang tidak mudah ditebak. Koneksi ke server sinkron dan lisensi memakai HTTPS.

7. Hak kamu

Sesuai Undang-Undang No. 27 Tahun 2022 tentang Pelindungan Data Pribadi, kamu berhak mengakses, memperbaiki, dan menghapus data pribadimu, serta menarik persetujuan. Kamu bisa melakukannya sendiri di aplikasi: Pengaturan › Backup (mengunduh salinan), Hapus semua data, atau Hapus akun dari HP ini. Untuk data di server sinkron atau lisensi yang dikelola pengelola, hubungi kontak di bawah.

8. Pengguna anak

FinFlow tidak ditujukan untuk anak di bawah 13 tahun dan tidak sengaja mengumpulkan data anak.

9. Perubahan kebijakan

Jika kebijakan ini berubah, tanggal berlaku di atas akan diperbarui dan perubahan penting akan diberitahukan di aplikasi.

Ketentuan Premium

  • Premium dibeli sekali bayar dan berlaku tanpa batas waktu untuk versi FinFlow yang tersedia, selama layanan lisensi masih berjalan.

  • Kode bersifat pribadi. Kode yang disebarluaskan, dijual ulang, atau terkait pembayaran yang dibatalkan dapat dicabut.
  • Pengembalian dana: [tulis kebijakanmu, mis. dalam 3 hari jika kode belum diaktifkan].
  • Versi gratis tetap bisa dipakai tanpa batas waktu. Jika Premium tidak aktif lagi, data tidak dihapus; hanya fitur Premium yang terkunci.
  • Aplikasi disediakan "sebagaimana adanya". FinFlow adalah alat pencatat dan bukan nasihat keuangan.
